# CodeAlpha_PhishingAwareness

Module interactif de sensibilisation au phishing, réalisé dans le cadre du stage Cyber Security CodeAlpha (Tâche 2).

## Contenu

- Simulation d'un e-mail frauduleux avec 4 éléments cliquables à identifier
- Comment reconnaître un e-mail de phishing et un faux site web
- Les leviers de l'ingénierie sociale (urgence, autorité, peur, curiosité, confiance)
- Trois cas réels documentés
- Bonnes pratiques de protection
- Quiz interactif de 6 questions avec correction immédiate

## Utilisation

Ouvrez `index.html` dans un navigateur, aucune installation nécessaire.

## Avertissement

Les adresses et liens cités dans l'e-mail simulé sont des exemples fictifs à but pédagogique.
